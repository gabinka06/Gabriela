===== КАК ДА ВИДИТЕ НАЛИЧНОСТ =====

НАЧИН 1: Отворете сайта в браузър
1. Отворете браузър
2. Отворете файла: file:///c:/Users/UEFI/Desktop/пепко/new 1.html
3. Под всеки продукт виждате:
   - 📦 Наличност: X бр. (зелено)
   или
   - ❌ Изчерпан (червено)

НАЧИН 2: Тестирайте поръчка
1. Отворете сайта
2. Кликнете "Преглед" на някой продукт
3. Видите наличност на детайлната страница
4. Добавете в количка
5. Отидете в количка → Поръчай
6. Проверете наличност - тя намалява!

НАЧИН 3: Управление чрез Python
1. Отворете терминал в c:\Users\UEFI\Desktop\пепко
2. Изпълнете: python main.py
3. Виждате всички наличности
4. Модулирайте inventory.json ръчно ако искате

===== ПРИМЕРНИ НАЛИЧНОСТИ =====

===== ТЕСТОВА ПОСЛЕДОВАТЕЛНОСТ =====

1. Зареждане на сайта:
   -> Видите наличности

2. Поръчка:
   -> Добавяте 2 бройки от продукт 1
   -> Натискате "Поръчай"
   -> Наличност намалява 15 -> 13

3. Обновяване:
   -> Обновете страницата (F5)
   -> Видите новата наличност 13

===== ДОПЪЛНИТЕЛНО =====

Ако нещо не работи:
1. Отворете Developer Tools (F12)
2. Отидете в Application -> LocalStorage
3. Видите "warehouse_inventory" с наличностите
4. Проверете Console за грешки

Ако искате да нулирате наличност:
1. Developer Tools (F12)
2. LocalStorage -> warehouse_inventory
3. Изтрийте запис
4. Обновете страницата
