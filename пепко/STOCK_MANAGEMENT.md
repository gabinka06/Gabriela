УПРАВЛЕНИЕ НА НАЛИЧНОСТ - БЪРЗО РЪКОВОДСТВО

===== НАЧИН 1: ЧРЕЗ PYTHON СКРИПТ =====

Стартирайте интерактивно управление:
python main.py manage

Изберете опции:
1. Покажи всички наличности
2. Добави наличност към продукт
3. Задай точно количество наличност
4. Покажи изчерпани продукти
5. Изход

===== НАЧИН 2: ДИРЕКТНО РЕДАКТИРАНЕ НА inventory.json =====

1. Отворете файла inventory.json
2. Намерете продукта по ID
3. Променете стойността на "stock"
4. Запазете файла

Пример:
{
  "products": [
    {
      "id": 1,
      "name": "Букет от лалета",
      "price": 29.99,
      "stock": 15  ← Променете тук
    }
  ]
}

===== НАЧИН 3: ЧРЕЗ БРАУЗЪРА (localStorage) =====

1. Отворете сайта в браузър
2. Натиснете F12 (Developer Tools)
3. Отидете в Application → Local Storage
4. Намерете "warehouse_inventory"
5. Редактирайте JSON стойността
6. Обновете страницата

===== ПРИМЕРИ ЗА ДОБАВЯНЕ НА НАЛИЧНОСТ =====

Python скрипт:
- Продукт ID 1: добави 10 бр. → става 25 бр.
- Продукт ID 5: задай 20 бр. → става точно 20 бр.

JSON редактиране:
- Намерете "id": 1, "stock": 15
- Променете на "stock": 25

Browser localStorage:
- Намерете {"1":15,"2":10,...}
- Променете на {"1":25,"2":10,...}

===== ВАЖНО =====

След всяка промяна:
1. Ако сте променили inventory.json - рестартирайте сайта
2. Ако сте променили localStorage - обновете страницата
3. Python скриптът автоматично запазва промените

Изчерпани продукти се показват с червено поле "Изчерпан"
