Проект: Управление на складова наличност за generation zef

Описание:
Този проект демонстрира управление на складова наличност за продуктите на сайта generation zef. Състои се от клас Warehouse в models.py, който позволява добавяне, премахване, проверка и сортиране на продукти.

Файлове:
- models.py: Съдържа класа Warehouse с методи за управление на продуктите.
- main.py: Основният файл, който създава обект от Warehouse и демонстрира използването на методите.
- requirements.txt: Списък с използваните библиотеки (само стандартни).
- readme.txt: Това описание.

Как да се използва:
1. Уверете се, че имате Python инсталиран (версия 3.6 или по-нова).
2. Стартирайте проекта с командата: python main.py
3. Скриптът ще покаже продуктите, ще ги сортира по различни критерии и ще извърши други операции.

Използвани библиотеки:
- Само стандартни библиотеки на Python (няма допълнителни зависимости).

Методи в класа Warehouse:
- __init__: Инициализира списъка с продукти.
- add_product: Добавя нов продукт.
- remove_product: Премахва продукт по ID.
- check_stock: Проверява наличността на продукт по ID.
- sort_products_by_price: Сортира продуктите по цена.
- sort_products_by_stock: Сортира продуктите по наличност (низходящо).
- get_total_stock: Изчислява общата наличност.
- display_products: Отпечатва всички продукти.
- find_low_stock: Намира продукти с ниска наличност.
